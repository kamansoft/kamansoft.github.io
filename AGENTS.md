 # Project conventions

- Hero diagram labels and icon names come from the hero JSON through its adapter and data service; the diagram renders typed steps so content remains source-independent.
- Tailwind `duration-*` utilities also override `animation-duration`, so an element that runs a keyframe animation must not carry a `duration-*` class; put the animation on a wrapper instead so it keeps its own speed.
- The navbar logo's breathing glow is its own layer: the keyframe animation element never carries a scroll-dependent class — the scroll state only changes that layer's opacity, so the glow keeps its phase, quiets while scrolled, and eases back to full when returning to the top.- Section visibility is controlled only by `src/data/site.json` via `SiteConfigService`; Index and Navigation both read it so hidden sections also lose their menu links.
- Explainer animations live in `src/components/graphics/` and play once via `useInView`/`useScrollProgress` (`src/hooks/use-in-view.ts`); wrap them in `.explainer` so reduced-motion users see the finished state.
- Site text is localized per language in `src/data/{lang}/*.json` (fixed UI strings in `ui.json`), loaded by adapters through `src/i18n/loadData.ts` with English fallback; `LanguageProvider` detects/saves the language and remounts the tree on change, so add a language by adding a folder and its code to `LANGUAGES`.
- The `ink`/`signal` "console" tokens are theme-aware (bright lab-white console in light, deep ink in dark); hero, nav and footer use only these tokens, and text on lime uses `signal-foreground`, so never hardcode white/gray/black there.
